# peakwhere

**Where do your peaks land?** Drop in a gene annotation and some peak files, and get a
chart of how your peaks split across promoters, UTRs, exons, introns and intergenic
space, entirely in your browser.

🚧 **Under construction.** See [`SPEC.md`](SPEC.md) for what's being built,
[`adr/`](adr/) for the decisions behind it, and the issues for progress.
